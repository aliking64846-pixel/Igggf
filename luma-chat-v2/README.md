# Luma Chat V2

نسخة تطويرية لتطبيق مراسلة ويب، بدون مكالمات صوتية أو مكالمات فيديو.

## الموجود في V2
- تسجيل وإنشاء حسابات بكلمات مرور مجزأة باستخدام bcrypt.
- طلبات صداقة وقبولها.
- رسائل فورية للأصدقاء المتصلين.
- إرسال نصوص وصور وفيديوهات كملفات داخل الدردشة (ليس مكالمات).
- مؤشرات الاتصال والكتابة وقراءة الرسائل عبر Socket.IO.
- حظر المستخدمين.
- واجهة ويب تحفظ سجل الرسائل محلياً في IndexedDB.

## التشغيل
1. Node.js 18+
2. `npm install`
3. عيّن متغير بيئة JWT_SECRET إلى سر عشوائي طويل (32 حرفاً على الأقل).
4. `npm start`
5. افتح `http://localhost:3000`

## حدود وأمان
- لا توجد مكالمات صوتية أو فيديو.
- الخادم لا يحفظ سجل الرسائل، لكنه يمرر محتوى الرسائل للمستلم المتصل؛ لذلك لا تعتبر المحادثات مشفرة طرفاً لطرف.
- لا تصل الرسائل للمستخدم غير المتصل في هذه النسخة.
- بيانات الحسابات والأصدقاء والطلبات والحظر تحفظ في data.json.
- استخدم HTTPS، أضف rate limiting والتحقق من البريد/الهاتف ونسخاً احتياطية قبل الاستخدام العام.
- ملفات الصور والفيديو محدودة الحجم في واجهة العميل.
- هذه نسخة أولية للاختبار وليست خدمة إنتاجية جاهزة.
